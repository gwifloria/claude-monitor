✦ Quick Start

Up and Running in 60 Seconds

Just four commands. Homebrew handles the rest.

1

Install SwiftBar

brew install --cask swiftbar
2

Install Claude Monitor

brew install gwifloria/tap/claude-monitor
3

Run Setup

claude-monitor-setup
4

Start Monitoring

claude-monitor start
💡

The setup script automatically configures Claude Code hooks and installs the monitoring plugin. No manual configuration needed.
